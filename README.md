# 🏎️ Cultura & Engenharia Automotiva — Projeto HTML Puro

Um site estruturado em **10 páginas interligadas**, focado na história dos carros esportivos, evolução dos motores, marcas icônicas e cultura automotiva nos videogames. Desenvolvido inteiramente em **HTML puro**, enfatizando semântica, organização e navegação web sem dependência de frameworks ou estilização externa.

---

## 📂 Estrutura do Projeto

O projeto foi organizado com foco em clareza arquitetural, separando mídias em pastas específicas e mantendo os arquivos `.html` no mesmo nível estrutural para otimizar caminhos relativos de navegação
